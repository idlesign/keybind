# keybind installation

Python `pip` package is required to install `keybind`.

## From sources

Use the following command line to install `keybind` from sources directory (containing `pyproject.toml`):

```shell
pip install .
```

## From PyPI

Alternatively you can install `keybind` from PyPI:

```shell
pip install keybind
```

Use `-U` flag for upgrade:

```shell
pip install -U keybind
```
